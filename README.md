# MBA ROI Analyzer

## Overview

MBA ROI Analyzer is a Python-based data analytics project that helps evaluate the financial viability of pursuing an MBA. The project analyzes MBA colleges based on fees, expected salary packages, return on investment (ROI), payback period, and salary growth projections.

The goal is to support data-driven decision-making for students considering higher education investments.

---

## Problem Statement

Pursuing an MBA requires a significant financial investment. Students often struggle to determine whether the expected salary growth justifies the cost.

This project helps answer questions such as:

* Which MBA college provides the highest ROI?
* How long does it take to recover MBA costs?
* How does an MBA compare to a non-MBA career path over time?
* Which colleges offer the best financial outcomes?

## Key Metrics

### ROI Percentage

Measures expected return based on salary increment after MBA.

### Payback Period

Estimates the number of years required to recover MBA investment.

### Salary Projection

Forecasts future salary growth based on user-defined annual growth rates.
